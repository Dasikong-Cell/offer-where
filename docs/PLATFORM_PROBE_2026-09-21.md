## 二、鱼泡直聘（yupao.com）—— 最值得先做

### 已探明的结构
| 项 | 实测值 |
|---|---|
| 城市入口 | 按 IP 自动跳 `/a367/`（昆明），城市 ID 在路径里 |
| 职位列表页 | `https://www.yupao.com/zhaogong/a367/` → **161 个详情链接**（`a[href*="/zhaogong/"][href$=".html"]`） |
| 列表项容器 | `class="acdif afih"`（混淆命名，但**按这组 class 稳定命中**，9 条/屏） |
| 详情页 | `https://www.yupao.com/zhaogong/{数字id}.html`（如 452830781）—— 可**匿名访问** |
| 详情页标题 | `h1` = 职位名 |
| 投递入口 | **`发送简历` / `聊一聊` / `拨打电话`**（三个按钮均在详情页） |
| 登录闸门 | 页面有「点击登录，立即与老板沟通」→ **投递动作必须登录** |
| JD 结构 | 招聘要求 / 招聘人数 / 薪资报酬 / 招聘有效期 / 工作地点 / 核心工作内容 / 岗位基本条件 + HR（姓名·职位·回复率）+ 工商信息（公司名/法人/成立日期） |

### 已知未解决
- **搜索参数名不是 `keyword`**：`/zhaogong/a367/?keyword=xxx` 被忽略（返回默认列表）。搜索框无 `<form>`（JS 提交）。→ 接入前需再探真实参数（试 `?key=` / `?kw=` / 或抓 XHR）。
- 薪资/公司无稳定 class（试 `[class*=salary]` 等均未命中）→ 需按详情页实际 class 精确校准（可用 JD 正文整段入库，字段留空亦可用）。
- 详情页含高德地图（`amap-marker-content` 命中我的宽泛选择器），说明**要避开 amap 相关 class**。

### 接入建议
1. 采集：列表页取 `a[href*="/zhaogong/"][href$=".html"]`（去重后可达 161 条/城市），详情页取 `h1` + 正文。
2. 投递：详情页点 `聊一聊`（或 `发送简历`）→ 需登录；建议先做 **preview 分支**（探测到按钮即返回，不点击）。
3. 城市 ID（`a367`=昆明）应做成可配置，而不是硬编码。

## 三、国聘（iguopin.com）—— 有 API，可能最省事

### 已探明的结构
- 列表页 `https://www.iguopin.com/job/list`：**前端异步渲染**，`<a>` 里没有职位链接（`/job/数字` 命中 false）。
- 但渲染后的卡片 class **语义化且稳定**：

| class | 含义 | 实测 |
|---|---|---|
| `.job-card` | 职位卡片 | ×20 |
| `.job-left` / `.job-right` | 卡片左右区 | ×19 / ×20 |
| `.job-name` | 职位名 | ✅ |
| `.job-district` | 地区（如「深圳-宝安区」） | ✅ |
| `.job-title` | 含完整 `title` 属性 | ✅ |
| `.job-flags` | 标签位 | — |

- 卡片内**只有 1 个 `<a>` 指向公司页**（`/company?id=...`）→ 点卡片进详情走 JS 跳转，不是链接。
- 卡片文本字段很全，可直接结构化：
  > 财富顾问（深圳宝安海秀路证券营业部）｜「深圳-宝安区」｜8~12K｜社招｜1-3年｜本科｜国投证券股份有限公司｜国企｜5000-10000人｜金融业

### 🔑 关键发现：公开 JSON 接口
页面实际调用的接口（`performance.getEntriesByType('resource')` 采集）：

```
https://gp-api.iguopin.com/api/jobs/v1/recom-job      ← 推荐职位（列表数据来源）
https://gp-api.iguopin.com/api/base/category/v1/by-alias
https://gp-api.iguopin.com/api/base/districts/v1/tree  ← 地区树
https://gp-api.iguopin.com/api/base/channelarticle/v1/list
https://api4.iguopin.com/api/spread/list
```

**建议优先验证 `gp-api.iguopin.com` 是否可匿名直接调用** —— 若可以，采集走 JSON 比 DOM 稳定得多（平台改版不影响接口）。

#### ✅ 已验证：接口匿名可调，但 `recom-job` 不是列表接口

实测（curl 直连，带 `Referer: https://www.iguopin.com/`）：

| 请求 | 结果 |
|---|---|
| `GET /api/jobs/v1/recom-job` | `{"code":405,"msg":"错误的请求方式"}` → **需要 POST** |
| `POST`（`{}` / `page` / `page_size` / `page_num` / `pageNo` / `current` / `limit` 等 6 组参数） | 全部 `{"code":200,"msg":"OK","data":{"total":0,"page":0,"page_size":0,"list":null}}` |

**结论**：
- ✅ 该接口**无需鉴权/签名**，匿名 POST 即可调用（返回规范信封 `{code,msg,data,trace}`）。
- ❌ 但它是**「某岗位的推荐位」**（`recom-job`，大概率需要 `job_id` 之类入参），**不是列表接口** —— 无参时恒返回空。
- 📌 列表页那 20 张 `.job-card` 的数据来源**尚未定位**（资源计时里只有上述辅助接口）。
  若要找真列表接口，下次需**抓真实请求体**（开 Network 域，或 hook `window.fetch`/`XMLHttpRequest`）。

**因此国聘采集的推荐路线是 DOM**：`.job-card` + `.job-name`/`.job-district`/`.job-title`（字段完整，见上表），
等 12s 让异步渲染完成即可；API 路线留作后续优化。

### 接入建议
1. 先探接口：直接 `curl https://gp-api.iguopin.com/api/jobs/v1/recom-job`，看是否需要鉴权/签名。
2. 不行再走 DOM：`.job-card` 卡片 + 点击进详情（详情页 URL 形态待确认）。
3. 国聘偏**央企国企**（与用户"软件工程/昆明"画像匹配度需评估；实测推荐位多为金融/深圳岗）。

## 四、店长直聘（dianzhangzhipin.com）—— 被风控挡住

**实测**：导航首页 → **未到首页即重定向**到

```
https://www.dianzhangzhipin.com/safe/verify-slider?redirect=/
```

页面文本仅 24 字：**「当前账号可能存在风险，请前往验证 点击进行认证」**

| 观察 | 含义 |
|---|---|
| 落地即 `/safe/verify-slider` | 首访就触发滑块/认证，与赶集招聘同类 |
| 文本含「账号可能存在风险」 | 命中的是 `riskSignals` 的 **account_risk** 类语义 |
| 无任何职位内容 | 探针无法继续 |

**这是 BOSS 同集团的风控策略**（店长直聘与 BOSS 共用后端风控），对全新 profile + 无登录态零容忍。

**处置**：需要在 9231 窗口里**人工完成验证 + 登录一次**（养熟 profile），之后才能探。当前不做无谓重试（重试只会加重风控）。
