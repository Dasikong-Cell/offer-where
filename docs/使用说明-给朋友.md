# OfferWhere 使用说明（给朋友）

> 一个能替你在招聘网站上自动投简历的工具。
> 装在**你自己的电脑**上，用**你自己的账号**，你的简历和数据**只存在你电脑里**。

---

## 一、开始之前，先确认两件事

| 检查项 | 要求 |
|---|---|
| 电脑系统 | **Windows 10 1803 以上**（Win11 也行） |
| 浏览器 | **要装 Google Chrome**（工具靠它去点招聘网站的按钮，没装用不了） |

> 不需要装 Node、不需要配置环境、不需要会写代码。

---

## 二、安装（约 3 分钟）

### 第 1 步：下载

打开这个地址：

**https://github.com/Dasikong-Cell/offer-where/releases**

下载最新版里的 **`OfferWhere-Setup.exe`**（约 362 MB）。

> 只有这一个文件要下载，其它不用管。

### 第 2 步：双击安装

双击 `OfferWhere-Setup.exe`，会弹出安装向导。

**⚠️ 会弹「Windows 已保护你的电脑」** —— 这是正常的，**不是病毒**。

原因是这个软件没有买代码签名证书（那要花钱）。处理方式：

> 点 **「更多信息」** → 再点 **「仍要运行」**

安装过程全自动，**约 1–3 分钟**。装到哪可以自己选，一路点「下一步/安装」也能装好。

> **不用管理员权限**，如果弹权限窗口，直接允许即可。

### 第 3 步：启动

装完后：

- 安装向导里有「**选择组件**」一页，默认勾选「在桌面上创建快捷方式」——**保持勾选**即可
- 桌面就会出现 **OfferWhere** 图标，**双击它启动**

如果没勾桌面图标，从**开始菜单**搜「OfferWhere」也能找到。

> 装完那一页还可以直接勾「运行 OfferWhere」，等于立刻启动。

---

## 三、第一次启动后：让「窗口」都出来

双击图标后，程序会**自动**做这些事（你不用管）：

1. 启动本地服务
2. 为 **5 个主要招聘网站**各开一个 Chrome 窗口
   （BOSS直聘 / 猎聘 / 前程无忧 / 智联招聘 / 官网渠道）
3. 打开操作界面（叫「控制台」）

**过一会儿**桌面上应该出现几个 Chrome 窗口 + 一个控制台窗口。

> ⚠️ 这些窗口是**独立**的，不要关掉。它们是工具在操作招聘网站用的。

---

## 四、关键一步：**在每个窗口里扫码登录**

这是**最重要**的一步。工具不会帮你登录，也不需要你的密码——
你需要在每个 Chrome 窗口里，用**手机扫码**登录对应网站。

| 窗口 | 登录方式 |
|---|---|
| BOSS直聘 | 手机 App 扫码 |
| 猎聘 | 手机 App 扫码 |
| 前程无忧 | 扫码 / 账号密码（**可能会弹滑块，手动滑一下**） |
| 智联招聘 | 手机 App 扫码 |

**每个网站都要单独登录一次**，因为它们互相独立。

> 💡 **登录一次就行了**。工具会把登录状态存在你电脑上，下次打开不用重新登。

### 🔴 怎么确认真的登录成功了？

**这一步最容易出错**，请务必按下面的方法确认：

打开控制台，点左边「**平台通道**」，每个平台卡片上有两个按钮：
**「检查登录」** 和 **「打开窗口」**。

点「**检查登录**」→ 状态显示 **「已登录」** 才算成功。

**为什么不能只看这个**：历史上多次出现「检查登录」说已登录、但实际搜出来 0 个岗位——
那是没真正登录。所以请再用控制台首页的「**开箱自检**」交叉验证。

### 首页的「开箱自检」是给你看的清单

控制台首页有张卡片叫「**开箱自检**」，会把「还差什么」直接列出来。一共 6 项：

| 自检项 | 说明 |
|---|---|
| Node 运行时 | 包内自带，**永远是「已就绪」**，不用管 |
| Google Chrome | 没装 Chrome 会显示「待处理」→ 去装一个 |
| 平台端口表 | 内置默认值，**正常就是好的** |
| **平台调试窗口** | **最常出问题的一项** —— 显示「已打开 N/15 个」，N 太少说明窗口没起来 |
| 简历 | 没上传会显示「待处理」→ 去「简历中心」上传 |
| AI 能力（可选） | 没配也是**可用**的，只是匹配质量略降 |

> 卡片右上角会显示「**N 项待处理**」。**把这个数字变成「全部就绪 ✓」再开始投递。**

如果「平台调试窗口」显示数量不够：
- 双击程序目录里的 `start_platforms.bat`（会再开 9 个平台窗口）
- 或在「平台通道」里点某个平台的「**打开窗口**」

> 如果点「检查登录」后提示要去过验证码，就切到那个平台的 Chrome 窗口，
> 把验证码/滑块手动过一下，再回来重新点一次。

---

## 五、填好「在线简历」

招聘网站投递时，用的是**你在该网站上填的在线简历**，不是工具里的。

所以请先在**每个网站**把自己的在线简历填完整：

- 工作/项目经历
- 教育经历
- 期望职位与城市
- 联系方式

> ⚠️ 简历不完整的话，投递会被网站拦掉，**表现是「投了但没成功」**，不容易发现。

**另外**：在工具里也上传一份简历。左侧边栏点「**简历中心**」→「**上传简历**」，
选 PDF / Word（≤ 8MB）。AI 匹配和文案会用到这一份。

---

## 六、开始投递

控制台左侧边栏 →「**投递中心**」。里面有「批量投递 / 自动回复 / 邮箱直投」三个页签，
默认打开的就是**批量投递**。

按从上到下填：

| 字段 | 怎么填 |
|---|---|
| **平台** | 选你要投的网站 |
| **来源（source）** | 一般不用改 |
| **目标城市** | 输入城市名/拼音搜（不选 = 全部城市） |
| **最低匹配分** | 默认 **40**。分太低会投一堆不相关的岗位 |
| **职位关键词** | 如 `Java,后端`，逗号分隔；**留空 = 全部** |
| **每日投递上限** | 默认 **40**。别调太高 |

下面有一排勾选框（默认已勾好，一般不用动）：

| 勾选框 | 作用 |
|---|---|
| 排除已投递 | 投过的不重复投（**建议保持勾选**） |
| 仅真实 JD 岗位 | 跳过只有图片、没文字的岗位 |
| 仅远程岗位 | 按需 |
| **模拟真人节奏** | **保持勾选** —— 它会放慢操作速度，降低被网站风控的概率 |
| 记录操作录像 | 出问题时可以回看（占空间，按需） |
| **仅预览（不真正投递）** | **第一次用请务必勾上它** |

**勾上「仅预览（不真正投递）」后点「开始投递」，它不会真的投**，但会完整走一遍流程：
检查登录态 → 加载岗位页 → 检测岗位是否已下线 → 抓取 JD → 探测投递按钮能否点。

**这一步是给你确认用的**：它会告诉你「哪些岗位投得出去、文案长什么样」。
确认没问题后，**取消勾选「仅预览」，再点一次「开始投递」**——这次才是真的投。

> 💡 别跳过预览直接投。预览能挡掉「登录其实没成」「岗位已下线」这类问题。

投递结果去左侧「**职位记录**」看，失败的岗位和原因都在那里。
界面上还有个「**停止**」按钮，投到一半不想继续可以随时停。

> 关于速度：**没有「间隔」可以调**，节奏由「模拟真人节奏」这个选项控制。
> **请保持勾选**，别追求快 —— 这也是最容易被封号的操作。

### 几个降低风险的习惯

1. **保持「模拟真人节奏」勾选** —— 别关掉它去追求速度
2. **每日投递别拉满** —— 默认 40 个够用了
3. **BOSS 直聘尤其要慢** —— 它反爬最严，登录后建议先手动浏览几个页面再交给自动化
4. **猎聘要放慢** —— 连续快速访问会触发短信验证
5. **先「仅预览」再真投** —— 别一上来就批量投

## 七、常见问题

### Q1：双击后提示「未知发布者」/「Windows 已保护你的电脑」

正常现象。点「**更多信息**」→「**仍要运行**」。

### Q2：没有出现 Chrome 窗口

1. 确认装了 **Google Chrome**（在「设置 → 应用」里看有没有）
2. 关掉**所有** Chrome 窗口，重新双击图标启动一次

### Q3：控制台显示「连不上后端」

- 等 10–20 秒再刷新（第一次启动比较慢）
- 还是没有的话，关掉所有窗口重新启动一次

### Q4：投递了但好像没成功

按顺序检查：

1. 平台上**真的登录了吗**？（见第四节，先看「开箱自检」是否全部就绪）
2. 平台的**在线简历填完整了吗**？（见第五节）
3. 打开左侧「**职位记录**」，看这些岗位的状态和失败原因

> 如果大部分都失败，通常是登录态掉了。回第四节重新确认一遍。

### Q5：会不会封我的号？

工具用的是**你的真实账号、真实浏览器**，通过「**模拟真人节奏**」放慢操作速度。
正常使用和人工点的节奏差不多。

但**如果你关掉「模拟真人节奏」、或把「每日投递上限」拉得很高，是有风险的**。

> **建议**：保持「模拟真人节奏」勾选，每日上限就用默认的 40。别贪快。

### Q6：我的简历和数据会被别人看到吗？

**不会。** 所有数据都在**你自己的电脑上**：

- 简历文件在你电脑的安装目录里
- 招聘网站的登录状态存在你电脑的 Chrome 配置里
- **不经过任何服务器**，也不会传给其他人

### Q7：想彻底删掉

「设置 → 应用 → 已安装的应用」里找到 **OfferWhere** → 卸载。

> 卸载时**默认会保留你的数据**（简历、投递记录），会单独问你一次要不要一起删。

## 八、还有个东西可以用：手机上看

如果你想把手机也变成操作端（同一 Wi-Fi 下）：

双击安装目录里的 **`start_lan.bat`**，它会打印一个手机能打开的网址。

> 方便躺着看投递进度。**但仅限你自己家的 Wi-Fi 用，别在公司/公共网络开。**
