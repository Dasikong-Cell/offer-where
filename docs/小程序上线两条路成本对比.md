## 零、先给结论

| 路径 | 一次性投入 | 持续成本 | 能达成什么 | 建议 |
|---|---|---|---|---|
| **① 只填表** | ¥0 | ¥0 | **小程序发不出去**（联网域名填不进去） | ❌ 别做 |
| **② 单人自用（真过审）** | 2–3 天开发 + 备案 1–4 周 | **¥100–1,000/年** | 你**自己**手机在外也能用 | ⚠️ 想要就做，但价值有限 |
| **③ 多人共用** | **3–5 人月** + 企业主体 | ¥1,000–3,000/年 + 代理/打码费 | 朋友的手机也能用 | ❌ 不推荐（见 §五） |

**一句话**：如果你要的是「朋友也能用」，**这三条路都不需要走** —— 正确答案是 0 成本的
「各自本地安装 + PWA」。这三条路只解决「你自己在外面用」。

## 一、三个硬约束（成本由它们决定，不是由技术决定）

### 1.1 🔴 三证合一：小程序主体 = 域名注册人 = ICP 备案主体

微信备案系统会**自动比对**三者（域名 WHOIS、工信部备案库、小程序后台管理员实名），
**任一字段不一致直接驳回**，包括姓名里的空格、括号差异。

> 实操含义：个人主体小程序 ⇒ 只能用**你本人身份证实名**的域名。
> 不能用家人的、不能买二手域名、不能开 WHOIS 隐私保护。

### 1.2 🔴 request 合法域名必须 https + 已备案，且不能填 IP

这是**路径① 走不通的直接原因**：

- 微信「开发设置 → 服务器域名」只接受 `https://` 域名，**不接受 IP、不接受 http**
- 当前小程序的联网方式是**用户手填局域网 IP**（`http://10.10.45.157:4400`，见
  `miniprogram/pages/connect/connect.js`）
- ⇒ **这个地址根本填不进合法域名框**。备案表单能提交，但代码无法配置联网域名 ⇒ 真机全报错。

### 1.3 🔴 个人主体：不能做招聘类目，不能有会员注册/UGC

2026 年微信服务类目规范（个人主体）：

| | 内容 |
|---|---|
| ✅ 开放 | **工具类**（通过率约 92%）、查询、图文展示、部分生活服务 |
| ❌ 封禁 | **招聘**、电商、金融、医疗、教育、直播、社交、资讯 |
| ❌ 封禁 | **会员注册**、任何支付/打赏、**公开评论/帖子/UGC** |

> 我们的定位「个人求职记录查看工具」落在**工具类**，是安全的 ——
> 但**这份描述不能出现「招聘」「职位发布」「信息撮合」字样**，否则：
>
> - 类目被判为「招聘」⇒ 个人主体不让选 ⇒ 直接驳回
> - 或按「招聘/信息撮合类」判 ⇒ 需要 **ICP 许可证**（增值电信业务经营许可证）：
>   **需公司主体、注册资本 ≥100 万、办理 20–40 工作日、费用数万元**

## 二、路径①：只填表（保持现状）

| 项 | 成本 |
|---|---|
| 钱 | **¥0** |
| 时间 | 填表约 30 分钟 |
| 开发 | 0 |

### 会发什么

1. **小程序备案本身可能通过** —— 表单只收集主体信息 + 类目 + 服务内容文字，
   工具类 + 个人主体 = 合规，微信初审 1–6 工作日 + 管局终审 4–15 工作日。
2. **但小程序跑不起来** —— §1.2：没有已备案域名可填进 request 合法域名。
   真机一打开就是「连不上后端」（我们**已经实测过这个报错界面**）。
3. **提交代码审核会被拒** —— 审核员打开发现功能不可用。

### 净收益

**只有一份「已填表」的自我安慰。** 而且留下了驳回记录。

## 三、路径②：单人自用（真过审）

目标：**你自己的手机在外面也能连上家里电脑的后端。**

### 3.1 一次性成本

| 项 | 工作量 | 说明 |
|---|---|---|
| 域名注册 | 10 分钟 | 阿里云/腾讯云 |
| 域名实名认证 | **1–3 工作日** | 必须与小程序主体同人 |
| 买国内轻量服务器 | 10 分钟 | 用于备案 + 做反向代理 |
| 提交 ICP 备案 | 30 分钟填表 | **免费** |
| 等管局审核 | **4–15 工作日** | 接入商初审 1–4 天 + 管局终审 4–15 天 |
| 配 HTTPS | 半天 | Let's Encrypt / 云厂商免费 DV 证书 |
| 开发：反向隧道 | **1–2 天** | 中转服务器把公网 HTTPS 转发到你家电脑的 4400 端口 |
| 小程序改配置 | 半天 | 把「用户手填 IP」改成「固定域名」 |
| **合计** | **约 2–3 天开发 + 1–4 周等备案** | |

### 3.2 持续成本（2026 年公开报价）

| 项 | 价格 | 来源 |
|---|---|---|
| ICP 备案 | **免费** | 工信部不收任何费用 |
| 域名 `.cn` | **¥30–50 / 年** | 2026 年价格 |
| 域名 `.com` | **¥50–80 / 年** | 同上 |
| 国内轻量服务器 | **首年 ¥60–99**；续费约 **¥300–1,000 / 年** | 云厂商入门级 |
| SSL 证书 | **免费**（Let's Encrypt / 免费 DV） | — |
| **合计** | **约 ¥100–1,000 / 年** | |

> ⚠️ 「¥60–99/年」通常是**新用户首年促销**，续费会跳到正价。按 ¥300–500/年 做预算更稳。

### 3.3 ⚠️ 这条路引入的新风险（容易被忽略）

| 风险 | 说明 |
|---|---|
| **后端暴露到公网** | 现在靠 `data/.auth_token` 这个**静态令牌**做唯一防线。`authToken.ts` 的注释里已实测记录：不带令牌时 `GET /api/resume/file` 返回 **348KB 简历 PDF**、`/api/profile` 返回姓名手机邮箱。放上公网后，这层防线要面对全网扫描。 |
| **家里的电脑必须常开** | 中转服务器只是转发，真正干活的还是你家电脑的 Chrome。关机 = 服务不可用。 |
| **备案期间不能上线** | 备案完成前不能开放访问，否则驳回。 |

### 3.4 关键局限：**只有你自己能用**

朋友手机连上你的域名 ⇒ 看到的是**你的**简历、投递记录、聊天记录。
这条路的收益是「你自己的手机能在外网访问」，**与「让别人也能用」无关**。

## 四、路径③：多人共用（真 SaaS）

详见 `MULTIUSER_SAAS_PLAN.md`。此处只列成本。

| 项 | 成本 |
|---|---|
| 数据模型改造 | 10 张表**全部无 `user_id`**，`profile` 是**单行** ⇒ 地基重做 |

| 法律 | 🔴 处理他人简历 ⇒ **PIPL 个人信息处理者**，泄露需担责（罚则可至上年度营业额 5%） |
| 账号风险 | 🔴 **封号责任在你**，不在用户 |

## 五、为什么路径③对「朋友自用」是**负收益**

这是一个**逻辑问题**，不是成本问题：

> 投递能力的物理前提是「**本机 Chrome 里已登录的招聘账号**」
> （BOSS 带 `__zp_stoken__` 签名、猎聘带 `X-XSRF-TOKEN`，见 `BOSS_OPENAPI_PLAN.md` §5.4）。

所以：

- 朋友要用 ⇒ 必须在他**自己的电脑**上跑 Chrome + 登录自己的账号
- 那他的数据就在**他自己的电脑**上
- 你的中转服务器对他**没有提供任何数据** —— 他手机要看的还是他自己电脑上的东西

⇒ **中转服务器对「朋友自用」这个目标是纯多余。**

朋友手机要看他自己的数据，正确答案是：
1. **同一 Wi-Fi** ⇒ PWA 直接访问局域网地址（**已有，实测可用**）
2. **在外面** ⇒ Tailscale / ZeroTier 组网（免费，5 分钟，**不用改一行代码**）

## 六、建议

| 你的真实目标 | 该做什么 | 成本 |
|---|---|---|
| 小程序能上线 | **先解决域名**，否则填多少表都没用 | 见路径② |
| 你自己手机在外面用 | 路径② **或** Tailscale（更省） | ¥100–1,000/年 **或 ¥0** |
| 朋友也能用 | **发安装包**（已有 Release）+ PWA（已有） | **¥0** |
| 陌生人也能用 | 路径③ | 3–5 人月 + 法律风险 |

### 我的建议

1. **如果只是想让小程序不白做** ⇒ 走路径②，但明确它服务的是**你自己**。
2. **如果目标是「朋友用得上」** ⇒ 停下小程序这条线，把力气花在
   **让朋友第一次安装能成功**（这是目前唯一没验证过的环节）。
3. **无论哪条** ⇒ **先把域名买下来跑备案**（免费，周期 1–4 周，是所有路的前置）。

### 待你确认

1. 这个小程序是**个人主体**还是**企业主体**？（决定类目与可行性）
2. 目标是「自己在外能用」还是「朋友也能用」？
3. 是否接受把后端暴露到公网（静态令牌 + HTTPS 是唯一防线）？
