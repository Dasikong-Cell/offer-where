自动填充 内置 CDP 通道 · 不用插件

offerbiu 的「自动填充」靠浏览器插件在招聘网站表单里回填。本项目不用插件：官网 / 网申投递走真实 Chrome + CDP 驱动，配一张按域名存下来的表单记忆表（form_memory，记住「字段标签 → 值」）——你在调试窗口里人工填过一次，下次同站自动复用。下面就是这条通道的操作台。

网申投递 企业官网 / 校招网申

网申 = 直接向企业官网招聘系统 / 校招网申系统投递。粘贴目标链接（每行一个），先「预览」只读探测投递入口与表单字段（不提交），确认无误后再「确认投递」真实提交。常规流程：在 9238 调试窗口打开官网 → 预览 → 人工补填必填项 →「记住当前表单」→ 确认投递。

「记住当前表单」把 9238 窗口当前页已填字段按域名存入记忆，下次同站自动填写（需先在窗口里人工补填）。

表单记忆 按域名自动复用

这里只列字段标签与条数，不回显值——表单里回填的是姓名 / 手机号 / 邮箱，把值摊在页面上等于把个人信息暴露在界面上。
点「刷新」读取已记住的表单。

自动填充信息 对标 offerbiu · 投递时自动带入

按真实投递表单的口径维护这 53 项。投递官网 / 网申时，后端拿表单上的字段标签到这份档案里取值回填（匹配顺序敏感：先「紧急联系电话 / 户籍所在地」这类具体规则，再「电话 / 城市」这类宽泛规则 —— 顺序反了会填得出值但值是错的，不报错）。姓名 / 手机 / 邮箱 / 期望职位 / 期望城市 / 简历路径仍归「个人中心 → 候选人档案」管：同一份数据不摆两份可编辑表单，免得「刚填完又被另一处覆盖」。
